# よくある質問

## ramdiskを編集するとboot.imgも編集されますか？

いいえ。ramdiskは別コンポーネントとして展開・再梱包されます。対応する`mkbootimg`でboot image全体を再構築し、flash前にAVBを確認してください。

## なぜ全ツールを自動ダウンロードしないのですか？

出所不明の実行ファイルを実行するのは危険だからです。Platform-Toolsだけは確認後にGoogle公式配布元から取得します。それ以外は上流プロジェクトを確認して導入してください。

## 端末へflashできますか？

自動flashは提供していません。解析、バックアップ、ログ取得、検証、安全な出力生成に集中しています。
